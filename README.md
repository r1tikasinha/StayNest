# StayNest 🏨

StayNest is a hotel booking Android application built using Kotlin and Jetpack Compose.

## Features

- Firebase Email/Password Authentication
- Hotel room listing
- Room details
- Multiple room booking
- Checkout
- Pay at Hotel option
- Booking confirmation
- User profile
- Last booking status
- Firebase Realtime Database
- Modern Jetpack Compose UI

## Tech Stack

- Kotlin
- Jetpack Compose
- Material 3
- Firebase Authentication
- Firebase Realtime Database
- Android Studio

## Firebase

Firebase is used for:

- User authentication
- Storing booking information
- Retrieving the user's latest booking

The Firebase configuration file is intentionally excluded from this repository for security reasons.
